# Рецептник: фронтенд

Проста сторінка для сайту з рецептами. Вона показує список рецептів і дозволяє шукати їх за назвою. Дані сторінка бере з бекенду через REST API.

Бекенд: [bogaevska-recipes](https://github.com/darynab-stack/bogaevska-recipes)

## Адреси і порти

| Що | Адреса |
|---|---|
| Бекенд (Django) | http://127.0.0.1:8000 |
| Фронтенд (Live Server) | http://127.0.0.1:5500 |

Бекенд дозволяє запити з `http://127.0.0.1:5500` і `http://localhost:5500` (налаштування CORS). Якщо запускати фронтенд на іншому порту, його треба додати в `CORS_ALLOWED_ORIGINS` у `config/settings.py` бекенду.

## Як запустити проєкт

1. Запустіть бекенд за інструкцією з його README. Він має працювати на `http://127.0.0.1:8000`.
2. Відкрийте цю папку у VS Code.
3. Встановіть розширення **Live Server**, якщо його ще немає.
4. Натисніть правою кнопкою на `index.html` і оберіть **Open with Live Server**.
5. Сторінка відкриється на `http://127.0.0.1:5500/index.html`.

Якщо бекенд не запущений, на сторінці з'явиться повідомлення, що не вдалося з'єднатися з сервером.

## Файли

- `index.html`: розмітка сторінки
- `styles.css`: стилі
- `app.js`: запити до API і відображення рецептів
